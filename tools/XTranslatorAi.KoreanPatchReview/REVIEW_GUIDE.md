# 스카이림 한글패치 검수 요청

이 폴더의 CSV는 스카이림 SE(DLC 포함) **유저 한글패치**의 번역입니다. 여러 사람이 손에서 손으로 고쳐 온 번역이고, 지금도 계속 다듬고 있습니다.
이 번역은 두 곳에 쓰입니다.

- 게임 화면 (패치를 설치한 사람)
- 모드 번역기: 모드가 원본 게임의 문장이나 레코드를 그대로 쓰면 이 번역을 그대로 가져갑니다

그래서 **틀리거나 어색한 번역을 고치되, 멀쩡한 번역을 취향대로 다시 쓰지는 마세요.**

## 파일

| 파일 | 내용 |
|---|---|
| `index.csv` | 묶음 목록과 행 수 |
| `01-used-by-mods-*.csv` | 실제 모드 번역에 쓰이는 문장. **가장 먼저** 봐 주세요 |
| `02-names-*.csv` | 이름(아이템, 주문, 장소, 인물 등) |
| `03-descriptions-*.csv` | 효과·아이템 설명 |
| `04-quests-*.csv` | 퀘스트 이름, 목표, 일지 |
| `05-books-*.csv` | 책 본문 |
| `06-dialogue-*.csv` | 대사 |
| `07-other-*.csv` | 그 밖의 문자열 |

열은 `plugin, table, id, rec, edid, source_en, current_ko`입니다. `rec`은 레코드:서브레코드(예: `WEAP:FULL`은 무기 이름, `INFO:NAM1`은 대사), `edid`는 레코드의 에디터 ID라 문맥을 짐작하는 데 쓸 수 있습니다.

## 봐 주셨으면 하는 것 (중요한 순서)

1. **오역**: 영어 뜻과 다른 번역, 반대 뜻, 빠진 내용
2. **불일치**: 같은 이름(아이템·주문·장소·인물)이 행마다 다르게 번역된 것. 어느 쪽이 더 많이 쓰이는지 근거를 적어 주세요
3. **오타·맞춤법·띄어쓰기**
4. **태그 손상**: `<mag>`, `<dur>`, `<Alias=...>`, `%`, HTML 태그 등이 영어와 다른 것
5. **어색한 문장**: 뜻은 맞지만 한국어로 매우 부자연스러운 것. 이건 확실할 때만

## 지켜 주세요

- 대사는 화자의 말투(반말·존댓말·하오체 등)가 일부러 다른 경우가 많습니다. 말투는 명백히 틀렸을 때만 고쳐 주세요.
- 엘더스크롤 고유명사는 네 기억 속 "정답"이 아니라 이 파일들 안의 다른 줄을 근거로 판단해 주세요.
- 태그와 자리표시자는 영어와 똑같이 남겨 주세요. 깨지면 자동으로 버려집니다.
- 확인한 것과 추측을 구분해 주세요.

## 결과 형식

CSV 하나(UTF-8). 열:

```
plugin,table,id,current_ko,suggested_ko,category,confidence,reason
```

- `plugin`, `table`, `id`, `current_ko`는 입력 CSV의 값을 **그대로 복사**해 주세요. 이 넷으로 줄을 찾고, `current_ko`가 지금 패치와 다르면 그 제안은 버립니다. 다른 줄의 값을 섞지 않도록 특히 조심해 주세요.
- `suggested_ko`에는 고친 번역 **전체**를 적어 주세요(일부만 적지 말 것).
- `category`: 오역 / 불일치 / 오타 / 태그 / 문장
- `confidence`: high / medium / low(추측)
- `reason`: 근거. 다른 줄을 근거로 들면 그 줄의 plugin·table·id를 적어 주세요.

CSV와 별도로 묶음별 짧은 요약(가장 심각한 문제, 반복되는 문제)을 적어 주세요.
