## 실제 실행 조건

- Google AI Studio Playground에서 모델별로 새 임시 채팅을 사용했습니다.
- 3.8 Flash, 3.5 Flash Lite, 3.1 Flash Lite 각각 **동일한 24문항을 한 번** 실행했습니다. 총 72개 번역입니다.
- 세 모델 모두 Thinking `Medium`, API 키 미선택, 검색·코드 실행 등 도구 끄기, JSON schema 끄기. 참조 번역은 모델에 보내지 않았습니다.
- 별도 결제, 무료 크레딧 활성화, 유료 API 호출을 하지 않았습니다. 로그인된 Studio의 기존 이용 범위에서 실행한 웹 비교이며, 무료 API 계정의 한도나 요금 상태를 테스트한 것은 아닙니다.
- 입력은 직접 작성한 합성 문장입니다. 사용자 프로젝트, API 키, 실제 게임 대사 파일을 외부에 보내지 않았습니다.
- 응답을 화면의 DOM에서 추출했고 저장한 JSON과 원문이 정확히 일치함을 확인했습니다. 모델의 추론 내용은 수집하지 않았습니다.

## 결과

형식 검사는 태그·변수·printf·줄바꿈·페이지 경계의 개수, 서식 순서, 지정 용어와 반복 웃음을 검사합니다. 세 모델 모두 JSON ID 24개와 **형식 24/24**를 통과했습니다. 이 수치는 의미 정확도 점수가 아닙니다.

모델 이름을 숨긴 A/B/C 자료를 별도 AI 검토자에게 주어 문장별 의미와 자연스러움을 평가했습니다. 사람의 블라인드 평가가 아니며, 부모 검토자가 실제 원문과 주요 오류를 다시 대조했습니다.

| 모델 | 0: 허용 가능 | 1: 경미한 어색함·용어 확인 | 2: 의미 수정 필요 | 3: 큰 오역 |
| --- | ---: | ---: | ---: | ---: |
| Gemini 3.8 Flash | 23 | 0 | 1 | 0 |
| Gemini 3.5 Flash Lite | 16 | 7 | 1 | 0 |
| Gemini 3.1 Flash Lite | 17 | 7 | 0 | 0 |

대표적으로:

- 3.8, 16번: 원문의 “위쪽에 있는 유적이 아니라”를 **“유적 위가 아닌”**으로 바꿔 위치 관계가 달라졌습니다.
- 3.5, 22번: `after sunset`을 **“해 질 무렵”**으로 옮겨 퀘스트 시간 조건이 달라졌습니다.
- 저비용 모델, 2~3번: `%(변수)` 주변의 **“(에게)”**, **“(으)로”**, **“%s(을)를”** 같은 부자연스러운 조사가 나왔습니다.
- 세 모델 모두 `Charge`를 폭약/돌격/충전 문맥으로 구별했고 의도적 `Ha Ha`를 두 번 보존했습니다.

인명 음역, 문맥이 부족한 `shield`, 소유대명사 등 판단이 불확실한 사례는 상세 JSON에서 별도로 표시했습니다. 표본이 작고 한 번만 실행했으므로 평균 품질, 장문 안정성, 재시도율, 지연 시간의 일반 순위나 통계적 우위를 주장하지 않습니다.

## 가격과 앱 선택

다음은 2026-09-28에 확인한 **API 표준 텍스트 가격**, 100만 토큰당 USD입니다. 웹 비교에 실제로 청구한 금액이 아닙니다. [Google 공식 가격표](https://ai.google.dev/gemini-api/docs/pricing)

| 모델 ID | 입력 | 출력(추론 포함) |
| --- | ---: | ---: |
| `gemini-3.8-flash` | $0.75 | $3.75 |
| `gemini-3.5-flash-lite` | $0.30 | $2.50 |
| `gemini-3.1-flash-lite` | $0.25 | $1.50 |

3.8 가격은 **2026-12-31까지의 한시 가격**이며, 공식 공지상 2027-01-01부터 $1.50/$7.50입니다. 앱의 가격표도 날짜별로 전환합니다. 입력/출력 토큰을 각각 동일하게 100만 개 사용한다고 가정하면 3.1은 $1.75, 3.8은 $4.50으로 약 61% 저렴하지만, 실제 추론 토큰·캐시·재시도량이 달라 실제 청구액 비율은 달라집니다.

기본 모델은 3.8을 유지하고 저비용 프리셋은 3.1을 우선 선택하도록 갱신했습니다. 당시 앱의 Lite 기본 추론 수준은 기존 정책인 `High`이며 이 웹 비교의 `Medium`과 다릅니다. 프롬프트, 마스킹, 용어집, 후처리도 적용되는 실제 앱의 품질은 이 raw 비교와 같다고 볼 수 없습니다. 최신 모델의 sampling 옵션과 지원하지 않는 다중 후보 요청을 피하고, 가격을 확인하지 않은 모델은 0원이 아닌 미확인으로 표시합니다.

DeepSeek 등 다른 제공자의 공개 가격은 조사했지만, 결제 없이 동일 모델 ID를 확정하여 실행하는 조건까지 확인하지 못했으므로 품질 비교표에 넣지 않았습니다. 이 앱의 현재 API 엔진은 Gemini입니다. [DeepSeek 공식 가격](https://api-docs.deepseek.com/quick_start/pricing/)
