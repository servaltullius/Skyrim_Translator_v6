# 현재 코드 검토 기준

- 완료 번역과 수동 편집을 보존하고 미완료·오류 항목을 이어서 처리한다. 의도적으로 비운 수동 편집도 보존한다.
- XML 가져오기 실패·취소는 기존 문자열·메모·프로젝트 정보를 복구해야 한다. 내보내기 실패는 기존 출력 파일을 보존해야 한다.
- 태그·변수·printf·개행·페이지 구분자는 API와 TM 양쪽에 동일한 무결성 검사를 적용한다. 서식 순서는 보존하되 문법상 필요한 런타임 변수 이동은 허용한다.
- 동일 원문이라도 레코드·EDID·확인 가능한 문맥이 다르면 무조건 결과를 공유하지 않는다. TES/Fallout/Starfield TM 경계를 지킨다.
- 번역, Compare, 비용 샘플의 모델·추론 정책은 공통 모델 정책을 사용한다. 모델 추가 시 지원 옵션과 요금을 별도로 확인한다.
- 비용 샘플은 API 사용량의 추론 포함 출력 토큰을 사용한다. 누락된 사용량을 0원 또는 실측값으로 표시하지 않는다. 취소를 일반 실패로 삼키지 않는다.
- 파일 전환·앱 종료 시 진행 중 HTTP/DB 작업의 취소와 정리를 기다리고 오래된 UI 갱신을 거부한다.
- 검증은 `./scripts/build.ps1 -Task Test`로 수행한다. 저장·런타임 변경은 실제 XML 왕복과 별도 배포본의 시작도 확인한다.
- mock·형식 검사·실제 번역 품질·게임 내 검증을 구분하여 보고한다. 유료 API 실행과 공개 배포는 일반 로컬 테스트에 포함하지 않는다.
