## 기본값과 새 옵션

| 설정 | 값/동작 |
|---|---|
| 기본 모델·추론 | 기존 `gemini-3.8-flash`, Low 유지 |
| 일반 요청 묶음 | 12행, 15,000자, 동시 2개 유지 |
| 의미 수리·태그 | 수리 켜짐, Soft, 원본 Skyrim 태그 유지 |
| 행별 추가 생성 상한 | 기본 8회, 설정 범위 0–100회. 0이면 실패 후 추가 생성 금지 |
| 전체 생성 상한 | 기본 0=자동. 양수는 작업 전체의 고정 호출 상한 |
| 출력 예산 자동 조절 | **기본 꺼짐**, 사용자가 켜는 실험 옵션 |
| 책 원문 문맥 | **기본 꺼짐**, 사용자가 켜는 실험 옵션 |

정상적으로 계획된 최초 장문 청크는 행별 추가 호출 8회에 포함하지 않는다. 재시도·수리·실패 후 분할·품질 재번역은 원본 행의 같은 추가 호출 예산을 사용한다. 모델별 실행이나 API 키가 바뀌어도 같은 작업의 카운터를 공유한다. 동시 요청에서도 검사와 증가를 한 번에 처리한다.

자동 전체 상한은 등록된 원본 행마다 `1 + ceil(마스킹 문자 수 / 128) + 보호 토큰 수 + 행별 추가 상한`을 합친다. 정상 장문 분할을 허용하기 위한 넉넉한 유한 상한이며 비용 예측치가 아니다. 같은 행을 재등록해도 사용한 호출은 복구되지 않는다. 전체 상한에 도달하면 이미 완료한 결과를 보존하고 아직 처리 중인 행만 Pending으로 되돌린다.

상한은 **생성 API 호출 수** 기준이다. 한 요청의 여러 후보도 1회이며, 토큰 수·금액 상한은 아니다. 캐시 생성/삭제, countTokens, 모델 목록, 별도 Compare·비용 샘플 작업은 이 번역 작업의 생성 상한에 포함하지 않는다. 설정의 MaxOutputTokens 역시 실제 사용량이 아닌 요청별 상한이다.

저비용/유료 프리셋은 기본 모델·처리량·캐시·출력 Auto만 조절하고 책 모델·품질 재번역·복구·실험 옵션은 유지한다. 적용 범위를 버튼 설명과 상태 메시지에 표시한다. 저비용 프리셋을 눌러도 별도로 켠 책/품질 모델이 저비용 모델로 바뀌지는 않는다.

## 실험 옵션의 범위

출력 예산 자동 조절은 원문 문자 수·보호 토큰·행 수로 여유를 둔 토큰 상한을 계산한다. 최소 4,096을 기준으로 256 단위로 올림하되 사용자/모델의 출력 상한을 넘지 않는다. 사용자 상한이 4,096보다 낮으면 그 낮은 값이 우선한다. 요청 크기도 출력 상한에 맞춰 제한한다. 이는 토크나이저 실측값이 아니며, 켜는 것만으로 청구 비용이 줄었다고 볼 수 없다. 기본 꺼짐에서는 기존 출력 상한을 유지한다.

책 문맥은 BOOK:DESC에만 적용한다. 선택된 행 중 BOOK:FULL과 정확히 같은 EDID의 유일한 원문 제목을 최대 160자로 참조한다. 제목 후보가 서로 다르면 생략한다. 분할 본문에는 이전 원문 청크 끝 400자와 다음 원문 청크 시작 400자를 참조로 넣는다. 번역 결과를 다음 청크의 문맥으로 연결하지 않는다. 참조에서 보호 토큰·태그·페이지 마커를 제거하며, 참조는 번역 대상이 아님을 지시한다. 선택 범위 밖의 제목이나 문서 전체 맥락을 자동으로 수집하는 기능은 아니다.
