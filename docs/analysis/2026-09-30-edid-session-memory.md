# EDID 문맥 전달과 세션 용어 기억 개선

2026-09-30. 기존 프롬프트 개선에 이어 EditorID와 자동 용어 기억의 전달·재사용 기준을 보완했다. Batch API와 Flex는 사용하지 않는다.

## 변경

| 항목 | 이전 | 변경 후 |
| --- | --- | --- |
| EDID | 읽어서 그룹·중복 구분에 사용하지만 모델에는 전달하지 않음 | 배치·단일 행·긴 책 분할·재검수·복구 요청에 참고 정보로 전달 |
| 원문과 EDID 충돌 | 명시 기준 없음 | EDID는 중의성 해결의 보조 단서이며 명시된 원문의 사실·동작을 우선 |
| 자동 용어 관련성 | 부분 문자열 일치 | 단어 경계를 확인하여 다른 단어·식별자 일부와의 잘못된 일치 방지 |
| 일반 단어·설정 문구 | Trigger 같은 대문자 단어와 Disable로 시작하는 설정 이름도 자동 학습 가능 | 흔한 동작어·기능어와 설정 동작 문구 제외. 사용자 확정·명시적 사전 입력은 허용 |
| 복수형 | 단순 부분 일치에 의존 | Weapon Art/Weapon Arts 등 한정된 다단어 이름의 복수형을 힌트로 연결. 일반 단어의 품사 변화는 추정하지 않음 |
| 번역 충돌 | 같은 이름의 첫 자동 번역을 계속 재사용 | 다른 자동 번역이 발견되면 해당 이름과 파생 힌트의 후속 재사용 중단 |
| 용어 우선순위 | 자동 후보와 확정 용어 구분이 일부 경로에 있음 | 수동 용어와 명시적 사전 입력 우선. 자동 후보는 강제 치환하지 않음 |

EDID가 없으면 생략한다. 160자를 넘거나 제어 문자·공백·마크업·번역 보호 토큰을 포함한 식별자도 전체 생략한다. 허용 문자는 문자·숫자·밑줄·하이픈·마침표이다. 데이터베이스나 플러그인 안의 원래 EDID를 수정하지 않는다. 비용 추정용 요청에도 EDID를 반영했다.

세션 용어는 실행 중에만 재사용한다. 자동 제안은 기존처럼 프로젝트 용어집에 **비활성 PromptOnly/WordBoundary**로 저장하며, 활성화 전 검수가 필요하다. 충돌한 아직 대기 중인 제안은 저장하지 않는다. 먼저 저장된 비활성 제안이나 사용자 용어를 소급 삭제·수정하지 않는다. 이미 번역된 행의 출력도 소급 변경하지 않는다. 단어 목록 기반의 보수적 제외이므로 모든 일반 단어나 동음이의어를 자동 판별하는 기능은 아니다.

## 검증

- .NET 테스트 837개와 Python 비교 테스트 6개 통과. EDID가 실제 배치·재검수·복구·단일·책 분할 요청까지 도달하고 출력 원문을 변경하지 않는지 확인했다.
- 자동 Trigger 제외, 실제 요청의 Weapon Arts 힌트, 부분 일치 방지, 수동 용어 우선, 번역 충돌 중단, 충돌 제안 저장 제외를 확인했다.
- Gemini 3.8 Flash Low로 엘든림 실제 원문 13개와 합성 경계 사례 3개를 EDID 전달 전후 각 1회 비교했다. 각 2회, 총 4회 생성. 양쪽 입력 파일·원문·빈 용어집·시스템 프롬프트는 같고, 이전 빌드는 EDID 속성을 무시한다. API 비교에서는 세션 학습·TM·캐시·재시도·재검수·ESP 내보내기를 실행하지 않았다.

| 확인 문구 | 전달 전 | 전달 후 | 판단 |
| --- | --- | --- | --- |
| ID 924: Disable NPC tumbling / DisableNpcDodge | NPC 공중제비 비활성화 | NPC 구르기 비활성화 | EDID가 회피 동작 해석에 도움이 된 사례 |
| ID 925: NPCs ... cannot use NPC Weapon Arts. / DisableNpcDodge | NPC 전투 기술 사용 불가 | NPC 전회 사용 불가 | 다른 동작을 암시하는 EDID가 있어도 원문 의미 유지 |
| 합성: Deal ... points of fire damage. / RestoreHealth | 화염 피해를 입힘 | 화염 피해를 줌 | EDID를 따라 체력 회복으로 바꾸지 않음 |

양쪽 각각 16행이 모두 반환됐으며 보호 토큰 불일치·예상 밖 ID·출력의 EDID 복사는 0건이었다. 합성 Charge 2개는 이전에도 레코드 정보만으로 돌진/충전을 구분했으므로 EDID의 개선 사례로 세지 않는다.

| 사용량 | 전달 전 | 전달 후 |
| --- | ---: | ---: |
| 입력 토큰 | 5,649 | 5,917 |
| 출력·추론 합계 | 615 | 789 |
| Standard 유료 단가 기준 예상 USD | $0.006543 | $0.0073965 |

입력은 이 표본에서 **4.74% 증가**했다. 비교 전체 예상 비용은 **$0.0139395**, 환율을 1달러=1,350원으로 가정하면 약 **19원**이다. 2026-09-30 확인한 [Google 공식 가격표](https://ai.google.dev/gemini-api/docs/pricing?authuser=0)의 Gemini 3.8 Flash Standard 입력 $0.75/1M, 출력·추론 $3.75/1M을 적용했다. 실제 계정 청구액·현재 환율을 확인한 수치는 아니다. 표본에서 비용도 늘었으므로 이 기능을 비용 절감으로 표현하지 않는다.

## 남은 검수

자동 용어 학습을 제외한 API 표본에서는 Weapon Art가 전회/전투 기술로 혼용됐다. 프로젝트에서 기준 용어를 검수해 활성화해야 한다. 자동 기억은 이미 선택된 번역의 반복 사용을 돕지만, 올바른 기준 용어를 독립적으로 보증하지 않는다.

ID 850의 reset이 새 결과에서는 지속시간 갱신으로 해석됐다. 원문만으로 확정하기 어려워 게임 동작과 대조가 필요하다. ID 892의 긴 고유명사도 수동 검수가 남아 있다. 한 번의 작은 비교이므로 전체 번역 품질 향상률로 환산하지 않는다. 실제 API 표본은 프롬프트 결과이며 전체 파이프라인 재번역·ESP 출력·게임 화면 검증과 구별한다.

증거: `artifacts/edid-session-review-20260930/`의 입력·선정 기록·원본 요청/응답·사용량·SHA256·테스트 결과·`comparison.html`·`summary.json`. 앞선 [프롬프트 개선 보고서](2026-09-30-prompt-improvement.md)와 증거는 보존한다.
