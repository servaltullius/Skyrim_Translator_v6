# 한글패치 3회차 검수: 번역기 검사 먼저 (2026-10-31~)

1·2회차는 사람이 읽어 고칠 줄을 찾았다. 이번에는 번역기 1.16.39의 품질 검사를 한패 본편 다섯 마스터에 돌려 후보를 뽑고, 기계로 확인하기 쉬운 것부터 덩이로 나눠 반영한다.

- 작업 폴더는 `artifacts/patch-review-r3check-20261031/`이고, 진행 상황은 `STATUS.md`에 있다.
- 사용자의 전역 DB·프로젝트는 건드리지 않았다(`--global`·`--projects`·`--work`를 작업 폴더로).

## 방법

1. **검사**: 영어 마스터를 에이전트 프로젝트로 열고(`open --strings`, 영어 strings는 `Skyrim - Interface.bsa`에서 꺼냄), 한패 strings로 채운 뒤(`korean --strings`), `check --all`을 돌린다(`run-master.sh`).
2. **모으기**: 서로 다른 줄 5,946개를 덩이 A~E로 나눴다(`collect.py`, `summary.md`).
   - A: 태그·자리표시자, 숫자, UI 조각의 앞뒤 공백, 보이지 않는 글자(약 300줄)
   - B: "<dur> 초 동안"의 띄어쓰기(323줄). 한패의 표기 규칙(`<mag> 의 피해`, `<dur> 초 동안`)과 반대라 고치지 않는 쪽을 권한다(사용자 결정 전).
   - C: 용어·이름(약 1,300줄), D: 말투(약 2,400줄), E: 끝 잘림·같은 원문 다른 번역 등(약 90줄)
3. **판단**: 하위 에이전트가 줄마다 고칠지 답하고(`a-review/`), 제안을 모두 직접 읽는다(`chunk-a-merge.py`).
4. **사본 확인**: 고친 한패 사본으로 다시 채우고 검사해, 새 경고가 없는지 본다(`compare-copy.py`).
5. **반영과 동기화**: `apply --write` 뒤 다음을 맞춘다.
   - USSEP 4판(`ussep-scan.sh`)
   - USCCCP(`usccp-check.py`)
   - TM
   - 사전(`build-dict.sh`)
   - 모드팩

  - 번역의 구간이 다르게 끝나거나(예: `</font>`가 빠짐), 한글이 든 구간이 원문 구간 뒤의 글을 먹은 경우(원문 구간 뒤에는 글이 있는데 번역에는 없음)는 되돌리지 않는다. 되돌리면 그 번역문이 사라지기 때문이다. 그 번역은 무결성 검사가 거부한다.
  - 품질 검사는 구간에 한글이 있으면 오류, 문장부호·띄어쓰기만 다르면(한패가 구간 안 영어의 하이픈 등을 바꾼 줄) 경고로 알린다.
  - 보호 조각은 구간과 다른 조각을 함께 글 순서대로 번호 매긴다. 룬 문자만 있는 줄(제조법)은 번역할 글이 없는 줄로 보고 요청 없이 원문 그대로 완료한다. 게임 번역 끼워 넣기와 프로젝트 용어 확인도 구간을 뺀다.
  - AI 번역: 마스커가 구간을 보호 조각 하나로 묶는다. AI가 구간 안을 볼 수 없고, 최종 검증이 원문과 같은지 확인한다.
  - TM·게임 번역·이전 번역판·한국어판 채우기와 후처리 재적용은 원문의 구간을 되돌린다.
  - 내보내기(플러그인, xTranslator XML)도 원문의 구간을 쓴다. 그래서 전에 번역해 둔 프로젝트도 저장이 막히지 않는다.
  - 품질 검사는 구간만 다른 줄을 "룬 문자 글꼴 안 번역"(오류)으로 알리고, 구간 안 영어는 미번역·영어 남음·용어 누락으로 세지 않는다.
- **튜토리얼 "~하세요":** "말투 불일치(같은 종류)" 검사는 합니다체가 대부분인 MESG에서 "~하세요" 안내(명령)를 해요체로 잡았다. 이제 MESG의 안내는 잡지 않는다(모든 문장이 안내나 합니다체이고 마지막 문장이 안내일 때). "~세요?" 물음, 인사("어서 오세요."), 안내 앞의 해요체 문장, 책·퀘스트의 "~세요"는 그대로 잡는다.
- **지속시간 틀:** "+<mag> 주어 for <dur> seconds"와 "기술 is <mag> points stronger" 틀이 표에 없는 주어를 영어 그대로 넣었다("<dur>초 동안 per second <mag>."). 이제 번역을 그대로 두고, 필요하면 자리만 바꾼다. 자리 바꿈 판단은 `<mag>` 뒤 "주문·일격·분노"의 첫 글자를 시간 단위로 읽지 않는다.
- **옛 판 TM 바뀐 행 파일:** 가져오지 못하고 남은 옛 판 파일(…-v7-changes.tsv)도 영어→한국어로 가져온다.
