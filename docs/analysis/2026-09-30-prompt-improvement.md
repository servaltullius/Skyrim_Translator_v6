# 3.8 Flash 번역 프롬프트 개선 — 2026-09-30

기준 커밋 `95873a9`. 엘든림 결과 보고서에서 발견한 문제를 근거로 사용자가 프롬프트 개선을 승인했다. 이번 범위는 Skyrim 기본 프롬프트, 공통 번역·수리 지시, 필드별 문체와 표본 검증이다. 자동 용어 기억의 매칭, EDID 전달, 용어집 데이터, LQA 연결은 이번에 변경하지 않았다. Batch API·Flex·모델 대체 없이 Gemini 3.8 Flash Low를 유지한다.

## 변경

- 기본 프롬프트에서 추상적인 페르소나·음절 압축·기계적인 음차 규칙을 제거했다. 인물·지명·아이템 이름은 적절한 용어집/통용 번역을 우선하고, 없으면 번역 또는 음차한다. 마지막 지시의 음차 강제와 충돌하던 부분을 통일했다.
- 보호 토큰·형식·원문 수치·단위·조건·부정·주체/대상 보존을 우선한다. 용어집은 같은 의미와 품사에만 적용하고, 참고 문맥으로 원문의 사실을 덮어쓰지 않도록 명시했다. 지명 Fast/Hold를 일반 동사·형용사에 적용하지 않는다.
- NPC/MCO 약어, 제품명, 키 표기의 영문 유지 예외를 추가했다. 한국어 조사 지시는 플레이스홀더 유무와 관계없이 배치·단일·수리 경로에 적용한다. 다른 대상 언어에는 새 한국어 전용 지시를 추가하지 않는다.
- BOOK 제목/본문, QUST 제목/목표/저널, DIAL 주제명/INFO 대사를 구분한다. 퀘스트 저널의 완료 시점을 목표형 명령문으로 바꾸지 않는다.
- 확률과 확률 증가량을 구분하는 지시와 조건부 예시를 추가했다. 예시는 원문에 `chance`가 있을 때 한국어 요청에만 추가하며 원문 payload는 바꾸지 않는다.
- 루트 참고용 `메타프롬프트.md`와 앱 내장 자산을 동기화했다. 사용자 정의 프롬프트를 덮어쓰거나 기존 번역을 재번역하지 않는다.

Google의 [Gemini 프롬프트 가이드](https://ai.google.dev/gemini-api/docs/prompting-strategies)에서 권장하는 직접적이고 구조화된 지시를 참고했다. [Gemini 3 가이드](https://ai.google.dev/gemini-api/docs/gemini-3)의 기본 temperature 권고에 따라 기존 생략 정책을 유지한다. 추론 수준을 High로 올리지 않았다.

## 실제 비교 방법

기존 빌드의 Core DLL·내장 시스템 프롬프트를 `baseline-build`에 먼저 보존했다. 동일한 입력 파일을 기존/수정 빌드의 `evaluate-prompts` 모드에 전달했다. 엘든림 Base 3.7.5의 실제 요청 문구 108개(보고서 진단 문구 포함, 나머지 요청 묶음은 seed 20260930)와 합성 경계 문구 12개다. 기존 한글판은 입력하지 않았다. 원문은 이전 요청의 보호 토큰 상태를 유지하며, 요청별 참고 용어집과 문맥도 고정했다. 새 자동 용어 학습·전역 TM·캐시·자동 수리·후처리·ESP 저장은 없다.

각 변형은 12개씩 10회 생성하며 같은 정확한 모델, Low, temperature 생략, JSON schema를 사용한다. 프로덕션 prompt builder를 사용하지만 전체 TranslationService의 마스킹·수리·복원 파이프라인을 재실행한 것은 아니다. 원문/용어집/문맥의 입력 SHA는 같다. 모델 출력은 비결정적이므로 한 번의 비교를 보편적인 품질 개선률로 해석하지 않는다. 진단 문구를 포함한 표본이며 984행 전체를 가린 평가가 아니다.

이 표본에서 입력 토큰 **9.13%**, 생성 비용 **6.86%** 감소를 관찰했다. 출력 길이와 변동성, 고정 용어집, 책·대사 비중, 캐시·수리 유무가 달라지므로 전체 모드의 절감률로 전용하지 않는다. 가격은 2026-12-31까지 입력 $0.75/출력(추론 포함) $3.75/백만 토큰인 [공식 Standard 가격](https://ai.google.dev/gemini-api/docs/pricing) 기준이다. 실제 계정의 무료 할당량·청구액은 판정하지 않았다.

효과 설명의 `triggers`는 `트리거합니다/트리거됩니다`에서 `발동합니다`로 바뀌었다. 확률 값·증가량, 초과/미만, 지속시간 등 선택한 효과 설명을 대조했다. 첫 수정안에서는 `chance of a critical hit`를 `치명타 확률 증가`로 옮기는 퇴행이 발견되어 채택하지 않았고, 확률 예시를 보완한 두 번째/최종안에서는 해당 문구가 `확률로 치명타가 발생`으로 돌아왔다. 중간 출력도 증거 폴더에 보존한다.

잔여 문제도 있다. `Disable NPC tumbling`은 기존 재실행에서 `구르기`, 수정안에서 `공중제비`였다. 모델에 `DisableNpcDodge`가 전달되지 않는 상황에서 프롬프트만으로 해결했다고 주장하지 않는다. Weapon Art의 `전투 기술/무기 기술`, 일부 책 제목의 표준 표기, `Increase Damage`의 `피해량/공격력` 표현도 용어집·레코드 문맥 검수가 필요하다. NPC 조사는 이번 재실행에서 양쪽 모두 올바르므로 개선 효과로 세지 않는다. 다른 문구로 바뀐 행의 수를 품질 점수로 사용하지 않는다.

## 검증과 증거

증거는 gitignored `artifacts/prompt-review-20260930`에 있다. `sample.json`, `sample-selection.json`, `baseline`, `candidate`(첫 수정안), `candidate-v2`, `candidate-final`, `summary.json`, 검색 가능한 `comparison.html`에 입력·프롬프트·Core 해시, 원시 요청/응답, usage를 보존한다. 로그에는 API 키·헤더·키 마스크를 쓰지 않는다. 네 변형 전체 실험 비용은 유료 환산 **$0.15310575**, 약 **207원**($1=1,350원 가정)이다.

기존 799개에서 언어/경로별 지시, 필드별 스타일, 조건부 확률 예시와 입력 불변 검증 10개를 추가했다. 마지막 .NET 회귀 809개와 Python 비교 테스트 6개를 통과했고 경고·오류 0개다. 게임 실행·설치 파일 수정·기존 번역본 교체는 하지 않았다.

프롬프트 개선 당시 루트 `TulliusTranslator.exe`를 `2026.09.30-prompt-preview6`로 교체했다. 66,750,022바이트이며 후보/루트 SHA256은 `2F13A8C4C770BED53C01A528A682DE119834DF4A7D4839ACDBA0FD9C5B8CBC93`로 같았다. 이전 preview5를 `deployment/TulliusTranslator.preview5.exe.disabled`에 보존하고 설정·API 키는 변경하지 않았다. 적용 기록은 증거 폴더의 `deployment.json`에 있다. EXE는 커밋 전에 제작했으므로 commit suffix는 당시 기반 HEAD이다. 프롬프트 개선 소스와 보고서는 후속 EDID·용어 기억 개선과 함께 커밋한다. 현재 루트 실행 파일과 검증은 [후속 개선 보고서](2026-09-30-edid-session-memory.md)를 따른다. 새 빌드의 실제 앱 화면 검사는 하지 않았다.

새 기본 프롬프트는 업데이트한 프로그램을 재시작한 뒤 적용된다. 기존 사용자 정의 지시는 유지되므로 별도 지시가 있다면 충돌 여부를 확인해야 한다.
