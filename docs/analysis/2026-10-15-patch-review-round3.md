# 한글패치 3차 검수 반영 (2026-10-15)

한글패치의 설명 2,644행을 두 모델이 따로 검수했다(`patch-review-round3-descriptions.zip`). 대상은 마법 효과·퍽·주문·방어구 설명, 로딩 화면, 메시지 상자 본문이다.
- GPT-6.1 Sol(Extra High, Codex 앱): 제안 224건
- Gemini 4 Argon: 제안 176건

두 결과 모두 네 열(plugin, table, id, current_ko)이 입력과 일치했다.

이번 자료에는 `ref-names.csv`를 넣었다. 2차 검수까지 반영한 화면 이름 16,155개의 대조표다. 설명 속 이름이 아이템·주문 이름과 같은지 확인하는 데 썼다.

## 두 검수 합치기

| | 줄 |
|---|---:|
| 둘 다 찾은 줄 | 134 (같은 수정 67) |
| GPT만 찾은 줄 | 90 |
| Argon만 찾은 줄 | 42 |
| 반영 | 255 (GPT 217, Argon 37, 직접 1) |

- **원칙**: GPT가 고친 줄은 GPT의 수정을 쓰고, Argon만 찾은 줄은 Argon의 수정을 쓴다. 같은 줄은 대체로 GPT 쪽이 더 완전했다. 다만 다음 줄은 Argon 쪽을 골랐다.
  - 생존 모드 음식 설명 5줄: 이웃 줄의 "온기가 <mag> 증가합니다"와 문체가 같다.
  - 지도 안내 1줄: GPT가 놓친 두 칸 공백도 고쳤다.
- **이름 근거 대조**: 두 검수가 근거로 든 `ref-names.csv`의 이름을 코드로 대조했다.
  - GPT가 든 이름은 모두 표와 맞았다.
  - Argon이 든 이름 9개는 표에 없거나 표와 달랐다: 데스 하운드, 스토니 크릭 동굴, 비 앤 바브, 절벽 은신처, 포 실드 선술집, 망자의 한 잔, 포 스컬 감시초소, 로스트 발리 보루, 화염탄.
  - 이 이름에 기댄 제안은 버렸다. 문장 수정이 맞는 경우에는 이름만 표의 표기로 바꿔 넣었다(유령 드래곤, 화염 화살).
- **게임 레코드로 확인한 것**: 흡혈귀 햇빛 약화 13줄. 주문에는 체력·매지카·지구력의 재생을 막는 효과와 수치를 깎는 효과가 함께 붙어 있다. 그래서 "재생 감소"로 옮긴 원래 번역이 틀렸다.

## 주요 수정

- **뜻이 반대로 된 줄**
  - 오라 속삭임·흡혈귀 생명 감지: 언데드·기계·데이드라를 "포함"하는데 "제외"로 옮겨져 있었다.
  - 드레모라 상인 가격: "10% 불리"인데 "10% 더 좋은 가격"이었다.
  - 은신 공격: 은신 중"이며" 발각되지 않은 상태인데 "이거나"였다.
- **숫자**
  - 바드 악기 300초가 30초였다.
  - 데스브랜드 흉갑 지구력 15가 10이었다.
  - 경갑 퍽 방어력 25%가 20%였다.
  - 고정 숫자와 `<mag>`가 뒤바뀐 효과 설명이 있었다.
- **조작 안내**
  - 쌍수 강한 공격은 두 키를 "동시에 길게" 누르는데 "번갈아"였다.
  - 충전 주문은 "손을 떼어" 시전하는데 "눌러서"였다.
- **빠진 내용**
  - 범죄 목록의 "물품이나 말 훔치기"
  - 카스태그 소환의 "야외에서만"
  - 환영마법 퍽 3개의 "마음 맞는 마법사·동물술사와 중첩"
  - 초당 피해, 지구력 2배 피해, 절반의 매지카 피해
- **옛 이름**: 생명력 흡수 → 생기 흡수, 냉기 숨결 → 서리 숨결, 성지 → 성역, 드래곤본 무기 → 드래곤 뼈 무기 등
- **영어로 남은 줄**: 생존 모드 설명, 나이팅게일 그림자, 위습 공격, 용의 폭풍, 화염 화살 마법책 효과
- **메시지의 `%%`**: 게임이 printf로 처리하는 메시지에서 `%`는 `%%`로 써야 하는데, 한국어에는 `%` 하나만 남아 있었다. 7줄을 고쳤다.
  - 반영 도구가 이런 수정을 막고 있어서 도구도 고쳤다(`7823925`).
  - 이제 도구는 영어에 가까워지는지를 판단할 때, 꺾쇠 태그뿐 아니라 검증기가 보호하는 텍스트(printf 이스케이프, 줄바꿈)도 센다.

## 반영 결과

- 한글패치 문자열 255개를 고쳤다. 다시 내보내 보니 계획한 255개만 바뀌었다.
- 게임 번역 사전을 다시 만들었다. 레코드 82,165개, 문장 20,190개다.
- TM 시드 v5에 47행을 더했다. v5는 아직 배포 전이라 같은 버전에 넣었다(v4에서 137행).

## 반영하지 않은 것

| 줄 | 이유 |
|---|---|
| Argon의 이름 근거 7줄 (Death Hound, 크리에이션 도움말 6곳) | 표에 없는 이름이다 |
| Argon의 마법부가 → 마법부여 연구탑 2줄 | 방 이름이 이름 26곳과 설명 전체에서 "마법부가 연구탑"이다. 바꾸려면 함께 바꿔야 한다(결정 필요) |
| Argon의 이동 도움말(Skyrim.esm) | Update.esm이 덮어써서 화면에 안 나온다. 제안 문장도 어색했다 |
| Argon의 보물 지도 설명 | 다른 지도 이름이 들어 있었다. 영어대로 직접 옮겼다 |
| GPT의 Seeker of Sorcery 메시지 | 한국어에 영어에 없는 마법부여 10%가 더 있어 `%%` 개수를 맞출 수 없다 |

## 결정 필요·다음 검수

- **Death Hound**: NPC 이름이 영어로 남아 있다. 로딩 화면 한 곳은 "지옥의 파수견"이라고 부른다.
- **마법부가 연구탑**: "마법부여"의 오타로 보이지만 하스파이어 방 이름 전체가 이 표기다.
- **GPT가 보류한 수치**: 원문 오류를 바로잡은 것일 수도 있어서 실제 효과 수치를 확인해야 한다.

  - 드래곤하이드 주문서 90%와 효과 80%
  - 스탈림 10%와 25%
