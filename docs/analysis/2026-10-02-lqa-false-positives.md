## 수정

- **조사**: 일반 단어 뒤에서는 단어 끝에 거의 오지 않는 조합만 본다. 받침 뒤 를·와, 받침 없는 글자 뒤 을·은이다. 을·은은 마을·수은·나은·지은 같은 단어를 뺀다. 용어집 번역어 바로 뒤에서는 그 글자가 확실히 조사이므로 모든 조사를 번역기의 조사 선택 함수로 검사한다.
- **조사 중복**: 어떤 명사 뒤에서도 틀리는 을를·은는·와과만 일반 검사로 본다. 야를을(야를+을)·성과와(성과+와)는 맞는 표현이다. 나머지 조합은 용어 바로 뒤에서만 검사한다.
- **영문 남음**: 원문에 그대로 있는 약어와 식별자(대문자 약어, 숫자 포함 이름)는 뺀다. 경고 문구에는 남은 단어를 보여 준다. `[ARMO:05000A6E]`는 한 덩어리 식별자로 보고, LotD의 `[page break]`는 서식 표기로 본다.
- **말투**:
  - ㅂ니다·ㅂ니까·ㅂ시다로 끝나면 모두 합니다체로, -아라·-어라 명령형은 해라체로 분류한다.
  - BOOK·QUST·MESG는 정해진 말투를 기대하지 않고, 같은 필드(예: MESG:DESC) 대부분과 다를 때만 경고한다. 프롬프트가 퀘스트 일지(CNAM)에 원문 시점 보존만 요구하고, 바닐라 일지는 해라체로 쓰기 때문이다.
  - 제목(FULL)과 버튼(ITXT)은 검사하지 않는다.
- **용어 누락**: 번역기와 같은 규칙으로 맞춘다. 기본 용어집의 대문자 한 단어는 대소문자가 정확히 같을 때만 보고, 긴 용어를 먼저 처리한 부분은 다시 보지 않는다.
- **기타**:
  - TM 폴백은 "참고"로 낮춘다.
  - 책 길이 비율은 원문 200자 이상에서만 "너무 짧음"을 본다. "Spell Tome: Thunderbolt"→"마법책: 벼락"은 정상이다.
  - 표의 심각도와 종류를 한국어로 보여 준다.

## 기본 용어집 추가 항목 (`8d79616`)

전역 용어집은 처음 만들 때만 기본 용어집으로 채운다. 사용자가 지운 항목이 되살아나지 않게 하려는 설계다. 그래서 preview12에서 추가한 "Elder Scroll(s) → 엘더스크롤"은 기존 사용자의 전역 용어집에 들어가지 않았고, 이름 안의 "Scroll"이 계속 "주문서"로 강제됐다. 평가는 새 전역 용어집으로 돌았기 때문에 이 차이를 드러내지 못했다.

이제 나중에 추가된 항목은 기존 전역 용어집에 없을 때 한 번 넣고, 전역 용어집 옆에 표시 파일(`.builtin-glossary-additions.2026-10-01.stamp`)을 남긴다. 그 뒤 사용자가 지우면 다시 넣지 않고, 같은 원문에 대한 사용자 번역은 덮어쓰지 않는다.

## 확인하지 않은 것

- 실제 앱 화면에서 프로젝트를 열고 품질 검사 표를 본 확인은 사용자 사용에 맡긴다. 검사 결과는 앱이 쓰는 `LqaScanner.ScanAsync`를 같은 DB 복사본과 용어집으로 호출해 측정했다.
- 로마자 약어 뒤 조사("NPC은" → "NPC는")는 철자가 아니라 읽는 소리로 정해야 해서 이번에는 다루지 않았다.
