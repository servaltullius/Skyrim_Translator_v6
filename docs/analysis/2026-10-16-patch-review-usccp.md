# USCCCP 한국어 검수 (2026-10-16)

## 저장소의 04-USCCCP는 버전이 맞지 않는다

- 저장소 `Skyrim_Latest_Kor/04-USCCCP`는 2023년 12월 파일로, 예전 USCCCP용 번역이다.
- 설치된 USCCCP 8.2와 맞대 보면 ID가 전부 어긋난다. 예를 들어 무기 "Sunder" 자리에 "악취나는 좀비 소환", 장소 "Gallows Hall" 자리에 "오크제 미늘 전투화"가 들어간다. 8.2에서 이 파일을 쓰면 화면에 엉뚱한 글이 나온다.
- 그래서 이 파일은 검수하지 않았다. 앱은 이 파일을 쓰지 않는다(게임 번역 사전과 TM은 기본 게임만 담는다).

## 검수한 것: MO2에 설치된 8.2용 한국어

- 대상: Nexus 163303 "USCCC (Merged) - Korean" 8.2, MO2 모드 폴더 `Unofficial Skyrim Creation Club Content Patches (Korean translation)`. 8.2 영어와 ID가 맞고 문자열은 523개다.
- 사용자의 결정으로 이 모드를 검수했다. 고친 문자열은 MO2 모드 폴더에 썼다. 원본은 `artifacts/patch-review-usccp-20261016/mo2-original/`에 복사해 두었다.
- 영어는 USCCCP 모드 폴더의 esl과 BSA에서 읽었다. 검수 도구의 `--plugins`에 USCCCP를 넘기고, Data 자리에 모드 폴더를 넣었다.
- USCCCP는 CC 레코드를 덮어써서, 이 번역이 화면에서 CC 번역을 대신한다. 그래서 같은 영어를 한글패치(방금 검수한 CC와 기본 게임)가 옮긴 표기를 `patch_ko` 열로 붙였다. Claude 하위 에이전트 하나가 523행을 읽었다.
