## Codex가 겪은 문제와 고친 것

| 문제 | 고친 것 |
|---|---|
| 프레아의 말투를 대기 중인 요청이 있을 때 정해, 그 요청의 답 30줄이 버려졌다. AGENTS.md는 "번역 중에 새로 정한 것도 그때 `style`로 남긴다"고 했다 | `style`로 정하면 대기 중인 요청을 정한 말투로 바로 다시 만들고 그렇다고 알린다. 갈래의 대기 요청이 있으면 `open`으로 다시 열라고 알린다 |
| PowerShell 함수로 부른 `--id 1008,383,…`이 여러 인자로 나뉘어 첫 id만 보였다 | `--id` 뒤에 이어지는 숫자 목록 인자를 모아 하나로 읽는다 |

| 게임 사전이 채운 바닐라 줄(#9, #38)을 정한 말투로 고쳤다 | guide-translate.md: 게임 사전이 채운 바닐라 줄은 한글패치 문장이니 말투 때문에 고치지 않는다 |
| "요청 10개마다"가 만든 요청인지 제출인지 모호했다 | "`submit` 10번마다"로 고쳤다 |

조사 보고서에서 가져온 것:
- AGENTS.md가 20,486바이트로 안티그라비티의 규칙 파일 한도(24,000바이트)에 가까웠다. 늘 지킬 규칙만 남겨 7,962바이트로 줄이고, 절차를 `guide-translate.md`, `guide-review.md`, `guide-lanes.md`로 나눴다. 맡은 작업의 안내만 읽는다.
- Windows PowerShell 5.1은 `Out-File`·`>`로 UTF-16, `Set-Content`로 CP949를 쓴다. 답·edit·인자 파일을 GUI 가져오기처럼 판별해 읽는다(f129853). AGENTS.md에는 두 판 모두에서 UTF-8을 쓰는 `[IO.File]::WriteAllText` 예를 넣었다.
- Codex는 작업 폴더에서 AGENTS.md를 찾으므로 사용법에 "agent-kit 폴더를 열 것"과 `codex --cd`를 적었다.
