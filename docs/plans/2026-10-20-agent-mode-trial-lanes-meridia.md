# 에이전트 모드 시험 7: 갈래 번역으로 Meridia's Order 다시 번역하기 (2026-10-20)

[시험 4](2026-10-19-agent-mode-trial-meridia.md)에서 하위 에이전트가 덩이를 차례로 맡아 번역한 Meridia's Order(4,062줄)를, 이번에는 갈래 3개(`--lane k/3`)로 동시에 번역했다. 갈래 번역의 속도, 버려지는 답이나 DB 잠김이 있는지, 갈래끼리 이름·말투가 얼마나 갈리는지를 보려는 시험이다.

- 시험 폴더: `artifacts/agent-trial-lanes-meridia-20261020/` (NOTES.md에 덩이별 기록)
- 빌드: 덩이 1은 루트 EXE 1.16-preview4(5f5bab5), 덩이 2·3과 검토는 시험 빌드 9e61b22
- 갈래 크기(원문 글자 수로 나눔): 1,447 / 1,334 / 1,281줄
- 부모(이 세션)가 말투를 정하고 덩이 사이에 갈린 표기를 맞췄다. 하위 에이전트는 AGENTS.md의 갈래 절차만 보고 번역했다.

## 결과

| | 시험 4(차례로) | 시험 7(갈래 3개) |
|---|---:|---:|
| 번역 걸린 시간 | 89분 | 37분(덩이 8분 30초 + 11분 30초 + 17분) |
| 하위 에이전트 토큰(번역) | 1,536k | 2,218k(+44%) |
| 다시 물은 줄 | 2 | 1(답에서 id 하나를 빠뜨림) |
| 버려진 답 · DB 잠김 | 0 · 0 | 0 · 0 |
| 검토 전 품질검사 | 101건(경고 72) | 73건(경고 39) |
| 검토 | 96줄 고침, 31건 남김 | 156줄 고침(+부모 5줄), 0건(확인함 4) |

- 시간은 2.4배 빨라졌다. 덩이 1만 보면 3.6배였는데, 뒤로 갈수록 갈래마다 lookup이 늘고 긴 줄(퀘스트 일지)이 몰려 느려졌다. 마지막 덩이는 가장 큰 갈래(1,447줄)가 끝날 때까지 기다렸다.
- 토큰은 44% 더 들었다. 갈래마다 지시를 읽고 같은 이름을 따로 찾아보기 때문이다. 사용량은 거의 같다던 앞선 예상보다 많다.
- 검토 전 경고가 줄어든 것은 말투를 미리 정해 둔 덕분이다(시험 4에는 `style`이 없었다).
- 다른 갈래가 저장해도 내 답이 버려지지 않았다. 갈래별 이름 기억과 같은 원문 묶기가 제대로 작동했다.

## 갈래끼리 갈린 것과 고친 것

| 덩이 | 갈린 것 | 고친 것 |
|---|---|---|
| 1 | 이름 5개(Reeshi 리쉬/리시, The Malevolent 악의단/말레볼런트, Dark Master 어둠의/암흑의 주인, pocket realm 소차원/주머니 차원, fetcher), 말투(Findar 하게체/반말, 플레이어 → Velteth 해요체/반말 등) | `lookup`이 이 모드에서 이미 번역된 줄을 보여 준다(`[이 모드에서 번역함]`). `style` 목록이 화자 30명과 플레이어 상대 20명을 보여 주고, 부모가 갈래 시작 전에 모두 정한다(9e61b22) |
| 2 | 이름은 동시에 처음 정한 Adelaide 하나(애들레이드/아델레이드). NPC끼리 하는 말투(알라라 → 베그라 반말/해요체 등) | `style` 목록에 NPC끼리의 쌍을 더했다(b7a7891). 부모가 쌍 20개를 정했다 |
| 3 | 이름은 갈리지 않음. 같은 갈래 안에서도 섞인 것(알라라의 1인칭 제/나, cult 교단/사교 집단, 마리스가 알라라를 부르는 말) | 검토에서 맞춤 |

덩이 사이에 부모가 말투를 더 정하면 대기 중인 요청이 달라진다. 그래서 `open`으로 다시 열어 대기 요청을 지운 뒤 다음 덩이를 시작했다(번역한 줄은 그대로 남는다).

## 검토에서 찾은 품질검사 빈틈 (고침)

정한 말투가 있을 때 놓치거나 잘못 짚은 경우다.

| 경우 | 고친 것 |
|---|---|
| 해요체로 정한 상대에게 하는 설득 선택지가 반말인데 짚지 않음(#2256 "…봐. 뻔하잖아. (설득)") | 설득·뇌물·거짓말 선택지도 정한 말투와 견준다. 위협·싸움 선택지는 지금처럼 뺀다 |
| 상대를 짐작한 줄이 정한 반말(두 상대 모두)과 달리 하오체(#2285 "그대의 뜻을 돕겠소") | 짐작한 줄도 두 상대에게 정한 말투와 견준다 |
| 반말로 정한 화자의 "자네"(#2255) | 반말에 "자네"가 있으면 하게체로 짚는다 |
| 합쇼체로 정한 줄의 해요체(#947 "…뿐이에요. …못 써요.") | 합쇼체로 정했는데 해요체로만 쓴 줄을 짚는다. 격식체에도 쓰는 ~지요·~군요는 짚지 않는다 |
| 하오체의 명사 "알던 자요"를 존댓말로 짚음(#654) | 꾸미는 말 뒤의 "자요"는 명사(자)+요로 읽는다 |

이 검사로 검토 뒤의 번역을 다시 보니 5줄이 더 나와 고쳤다. 드랄로스에게 하는 설득 선택지, 베그라와 우나가 알라라에게 한 해요체, 알자카르의 "자네"다.

## 시험 중의 실수

- 검토 전 DB 백업에 `-wal` 파일을 빠뜨려, 백업이 덩이 3을 다 담지 못했다. 백업은 `.sqlite`·`-wal`·`-shm`을 함께 복사해야 한다.
- 확인용으로 작업 폴더를 복사해 `edit`했더니, `project.json`이 실제 DB 경로를 가리켜 실제 DB의 5줄이 바뀌었다. 바로 검토 후 문장으로 되돌렸다. 작업 폴더 사본은 실제 DB를 가리킨다는 점에 주의해야 한다.

## 남은 것

- 갈래 번역은 시간을 크게 줄이지만 토큰은 40% 안팎 더 든다. AGENTS.md 갈래 절의 첫 문단에 이 차이와 고르는 기준을 적었다.
- 동시에 처음 정한 새 이름은 여전히 갈릴 수 있다(이번에는 Adelaide 하나). 검토의 `show --find`로 맞춘다.
- 플러그인이 상대를 알려 주지 않는 줄(#2183 "Champion, …"인데 상대가 알라라로 짐작됨)은 화자 정보로 고칠 수 없었다.
