# 번역 파이프라인·기본 설정 개선

사용자가 재검수 결과의 구현을 승인했다. 기존 미커밋 개선을 보존한다. Batch API/Flex는 제외한다.

- [x] 오류별 복구 분류: 인증·할당량·서버/네트워크 오류는 허용 재시도 후 분할하지 않음
- [x] 원본 행별 추가 생성 호출 상한과 작업 전체 생성 호출 상한, 모델 분리·키 전환에서도 예산 공유
- [x] 완전한 JSON에서 검증한 정상 결과를 저장하고 누락·실패 행만 다시 요청; 중복/알 수 없는 ID는 거부
- [x] 번역 설정 저장, 초기 로드 중 덮어쓰기 방지, 지원 모델의 실제 후보 수 표시
- [x] 출력 예산 자동 조절·책 원문 문맥을 기본 꺼짐 실험 옵션으로 제공, 기존 수치 유지
- [x] JSON/단일 요청 문체 지시 공통화
- [x] 임시 DB/HTTP fixture 회귀 테스트·전체 빌드, 검증 보고서와 별도 실행 파일 생성

실제 유료 API 평가 없이 품질 향상률·비용 절감률을 단정하지 않는다. 사용자 설정/DB는 검사하지 않는다. 이전 실행 파일 교체·시작 확인 명령이 자동 승인 검토에서 차단되었으므로, 이번에는 해당 동작을 재시도하지 않고 별도 빌드 산출물을 제공한다.

분담: 주 에이전트는 파이프라인·통합 검증, 설정 에이전트는 App 설정 저장/UI와 해당 테스트를 담당한다.
