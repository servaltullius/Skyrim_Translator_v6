# ESP 직접 지원 구현·검증 계획

사용자 목표: "완벽하게 문제없이 esp 지원 되도록 진행". XML 수동 추출 없이 플러그인을 열고, 기존 AI 번역·용어집·검수를 사용한 뒤 게임에서 사용할 번역본을 저장한다. 완성 판정은 기능 구현과 보존·독립 도구·실제 사용 검증을 구분하여 내린다. 일부 parser 테스트만으로 모든 ESP의 무결성을 주장하지 않는다.

## 구현 계약

- [x] 플러그인 전용 입력 모델과 DB 출처 키. XML 저장 데이터와 분리, 재열기 번역 복원.
- [x] Skyrim SE/AE에서 사용하는 ESP/ESM/ESL 및 ESL-flagged ESP의 레코드/GRUP/XXXX/압축 구조 파싱.
- [x] 개발 도구의 필드 정의에 근거한 번역 대상 선택: 이름·설명·책·대사·퀘스트·메시지·조건부 표시 문자열. 기술 식별자·경로 제외.
- [x] inline/localized 양쪽 처리. STRINGS/DLSTRINGS/ILSTRINGS 구분, 원래 ID 유지, 원본 언어/인코딩/실제 입력 경로 기록.
- [x] 필요한 loose/BSA 문자열 검색. 누락·중복/상충·지원 범위 밖 입력을 조용히 성공 처리하지 않음.
- [x] 원본 플러그인 보존, 번역 필드 이외 payload·FormID·masters·flags·record order 불변. 변경 레코드/상위 그룹 길이만 갱신, 무변경은 원본 바이트 그대로.
- [x] 별도 출력 폴더에 동일 플러그인명과 필요한 문자열 파일을 함께 확정. 원본 변경 감지·출력 충돌·취소/실패 처리.
- [x] 앱의 직접 열기/저장·형식/게임/인코딩 선택·번역/비용/문맥/작업 종료 수명주기 통합.
- [x] 합성 경계값/손상 fixture 및 USSEP·Skyrim.esm·BSA 기반 localized 소형 ESL 자동 검증.
- [x] 사용자 요청에 따라 실제 모드 검증을 엘든림 본체/전회 ESP로 변경. 본체 985개·전회 2,852개 읽기와 무편집 SHA 보존, 전회 편집본의 xEdit 2,852개 전수 대조 통과. LOTD 자체를 검증한 것으로 표현하지 않음.
- [x] xEdit 구조 검사와 노출 필드 전체의 원문/번역 대조, 기술 식별자 보존 실패 대조.
- [x] USSEP의 독립 reader translated getter 목록으로 선택 누락을 별도 점검: Mutagen 57,205개 major record, 18,870개 비어 있지 않은 번역 문자열 전부 일치. plain 문자열 전체 및 다른 모드의 완전성으로 확대하지 않음.
- [x] 전체 회귀 테스트·별도 후보 빌드·검증 범위 기록.
- [ ] 사용자 관점의 실제 화면 조작·취소·재개 및 게임 표시/대사/퀘스트 동작 검증. SNDR 공유 ID의 간접 변경 영향도 미확인. VM 테스트와 실제 화면/게임 증거를 구분함.

현재 변경 중인 일반 API 최적화 작업은 보존한다. Batch API/Flex와 유료 모델 평가를 추가하지 않는다. 게임 설치·활성 MO2 프로필·원본 플러그인을 변경하지 않는다. 게임별 구조는 검증된 명시적 GameRelease로 처리하며, Fallout/Starfield 파일을 Skyrim 구조로 추측하지 않는다. 현재 XML 경로의 세 프랜차이즈 지원을 유지한다.

## 분담

주 에이전트: 바이너리 reader/writer 및 통합 검증. 형식 조사 에이전트: 독립 필드 규칙/보존 설계 검토. App 에이전트: DB·프로젝트 수명주기·UI 통합 설계 후 독립 파일 구현. 검증 조사 에이전트: 실제 corpus와 독립 검증 도구 조사.

진행 중 요구사항/검증 증거를 이 문서에 갱신한다. 미구현·미검증 항목이 남으면 목표를 완료로 표시하지 않는다.

## 2026-09-29 구현 후 재검증

이전 `esp-preview`는 PERK EPFT=6 기술 식별자 오분류로 사용 중지했다. xEdit 구조 검사는 이 오류를 잡지 못했다. 다음 결과는 PERK 수정과 취소·응답성 수정, 보존 안내 정정을 포함한 `esp-preview4` 기준이다. USSEP/xEdit 검증은 동일한 바이너리 해석·저장 로직을 사용한 preview2 산출물을 유지하며, Skyrim 지역화 전체 편집 증거를 추가했다.

- 전체 Release 테스트 **797/797**, App/test 및 Validate CLI 빌드 경고/오류 0. 네트워크 번역은 가짜 HTTP이며 유료 API 호출 없음.
- USSEP **18,870개** 표시문구 전체 수정 후 내부 보존 검사 및 xEdit 4.1.5f 검사 통과. 원본/출력 전체 dump의 모든 기대 문구 일치, 누락·불일치·문자열 경계 오류 0, 기술 변수 변경 0. 이전 후보는 같은 대조 도구에서 변수 변경 1건으로 실패한다.
- Stendarr 지역화 ESL의 BSA 105에서 3종 테이블 읽기, WEAP 이름 한글 저장, ESL SHA 불변. xEdit 한글 decode 확인 결과와 같은 출력 세트 재생성.
- Skyrim.esm **67,388개** 표시문구 읽기·무편집 저장 성공, ESM 및 문자열 테이블 3종 SHA 불변. 기술 변수 3개 제외.
- 읽기·저장 전체를 백그라운드로 옮기고 취소 버튼을 상태 표시줄에 유지했다. STA 취소 및 DB 확정 후 늦은 취소 등 회귀 4건 추가. 실제 창 조작 증거와는 구분한다.
- LZ4 후행 데이터·중복 nonzero FormID·PERK 기술 변수·대화 topic/부분 재개 TM·Compare TM 우회·LQA 보호 요소·공유 ID 검색·오류 복구 회귀를 통합했다.
- 필드 정의: xEdit 134개 레코드 서명과 Mutagen schema 149개 대조. 최초 정적 분류의 PERK 오류를 실제 입력 근거로 수정했다. 상세 [보고서](../analysis/2026-09-29-plugin-field-registry.md).
- 독립 Mutagen 목록과 USSEP 18,870개가 양방향 차이 없이 일치. 일반 문자열을 별도 보존하고 `bPerkShieldCharge`가 plain 분류임을 확인했다. 중단된 이전 시도는 실패 기록으로 보존하며, 최신 도구의 성공 증거는 `ussep-mutagen-inventory-v4.json`과 최종 요약 파일이다.
- Skyrim.esm 67,388개 전체 편집 후 ESM 바이트·전체 테이블 ID·미편집 26개 항목 보존 확인. 원문/수정문 모두 앱 노출 항목 67,388개가 별도 파서와 일치했다. 외부 reader 진단 9건과 SNDR 추가 해석 54개는 별도 기록하며 전체 reader 성공으로 바꾸지 않았다.
- SNDR:FNAM의 필드 바이트 보존과 공유 ID에 의한 참조 내용 변경을 구분했다. preview4는 앱 안내의 과도한 보존 표현을 수정한다. 실제 게임 영향은 확인하지 않았다.
- 별도 `candidate-preview4` Windows x64 후보 publish 완료. 이전 후보는 `.disabled`로 보존. 원래 루트 EXE와 게임/MO2 파일 보존.

2026-09-30 사용자는 LOTD 대신 엘든림을 선택했으며, 게임 실행 및 화면 확인은 직접 담당한다고 명시했다. 저장 API 키를 삭제하고 설정 복원 없이 루트 EXE를 교체·실행하는 작업은 거절 없이 완료했다. 실제 화면에서 전회 ESP 열기·무편집 저장·한글 수동 편집·편집 저장·작업 재열기를 확인했다. 이 과정에서 발견한 수동 편집의 진행 숫자 미갱신을 preview5에서 수정했으며 회귀 테스트 799/799를 통과했다.

게임 표시·동작 및 SNDR 공유 ID의 실제 영향은 사용자 확인 항목으로 남긴다. 이 위임은 해당 증거를 확보했다는 뜻이 아니다. 상세한 현재 범위는 [엘든림 검증 기록](../analysis/2026-09-30-eldenrim-validation.md)에 있다. 모든 파일/게임 동작의 무오류 보장으로 표현하지 않는다.
