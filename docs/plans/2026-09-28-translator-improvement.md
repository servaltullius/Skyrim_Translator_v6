# 번역기 전면 개선 및 무료 모델 비교

## 목표와 근거

사용자 요청: 현재 번역기를 모든 면에서 개선하고 더 나은 방식이 있으면 재설계한다. Gemini 3.8 Flash보다 저렴하면서 번역 품질이 좋은 모델을 비용이 들지 않는 범위에서 비교한다. 낡은 문서와 파일은 보관하거나 최신화한다. ESP·ESM·ESL 직접 번역은 완전한 지원이 가능한지 조사한 뒤 도입 여부를 판단한다.

현재 working tree의 미커밋 작업을 기준으로 삼는다. 2026-09-28 분석에서 앱/Core 빌드 경고·오류 0, 테스트 329/330 통과. XML 행 누락, 한 줄 XML 내보내기 손상, 실패한 가져오기의 이전 행 손실, TM 보호문자 검증 누락, 인접 용어 반복 축약을 임시 데이터로 재현했다.

## 제약과 보존

- 기존 사용자 변경, 실행 파일, 번역 자산, 실제 사용자 DB를 보존한다. 커밋·푸시·공개 배포는 수행하지 않는다.
- 개선 전 소스/문서/테스트 스냅샷: `artifacts/improvement-20260928/before-improvement.zip`.
- 유료 API 호출, 결제/요금제 변경, 무료 크레딧 소진에 의존한 호출은 하지 않는다. 무료임이 확인된 경로 또는 로컬 실행만 사용한다.
- 모델 품질은 동일한 입력/문맥/평가 기준과 실제 출력으로 비교한다. mock 검증을 실제 번역 품질로 보고하지 않는다.
- 기존 실행 파일을 덮어쓰지 않고 검증된 후보를 별도 패키징한다.

## 설계 원칙

WPF 화면, 프로젝트 저장, 번역 실행, 결과 검증을 분리한다. 유효한 기존 모듈을 유지하며 데이터 손실과 숨은 상태 공유를 우선 제거한다. 근거 없이 전체 재작성하거나 기능을 줄이지 않는다.

## 검증

변경 영역별 회귀 테스트 후 단일 통합 빌드/테스트를 수행한다. XML은 원본 행 수·식별자·Source·Dest·속성/태그와 출력 파싱을 비교한다. 실패와 취소는 이전 작업 보존 여부를 검사한다. 번역은 태그/변수/문맥/용어/자연스러움을 분리 평가하며 API 실험의 모델 ID, 날짜, 무료 조건, 출력과 평가 한계를 남긴다.

## 진행 및 남은 일

2026-09-28 구현과 검증을 마쳤다. App/Core/Tests 빌드 경고·오류 0, 전체 452개 테스트 통과. 실제 XML 두 개 38,007행의 원본/DB/출력 왕복과 수정 DB의 Dest 보존을 확인했다. 별도 EXE 시작 및 ZIP CRC/실행 파일 해시를 검증했다. 무료 Studio 비교는 24문항 × 3모델이며, 자동 형식 검사와 이름을 숨긴 독립 AI 평가를 기록했다. ESP/ESM/ESL 직접 쓰기는 완전 지원 조건의 증거가 부족하므로 활성화하지 않는 것으로 판단했다. 게임 내 검증, 유료 API 호출, 공개 릴리스는 이번 완료 범위가 아니다. 자세한 증거와 한계는 [검증 보고서](../../artifacts/improvement-20260928/verification-report.md), [모델 비교](../../benchmarks/translation/README.md), [플러그인 검토](../direct-plugin-feasibility.md)에 기록했다.
