# Release 1.4 Candidate Cleanup Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Isolate a defensible `1.4` release subset from the current dirty worktree without accidentally shipping unrelated repo-maintenance or large core refactors.

**Architecture:** Treat `1.4` as a narrow release branch cut. Keep the already-committed `1.3 -> HEAD` changes as the base release spine, then selectively include only the `Franchise TM` UX/service rename set from the current uncommitted changes. Exclude repo-ops files and defer large `Core/Text/Translation` refactors to a later release.

**Tech Stack:** Git, .NET 8, WPF, xUnit, local release process
